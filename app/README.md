# 满意度自动测评平台

内部支撑岗位（平台运营支撑 / 网络终端技术支撑 / 投诉管理（班长））月度满意度自动测评系统，替代原「问卷星 + 人工统计」模式。

## 功能

- **全流程自动化**：评价周期自动启动（通知）、按三类工种自动生成问卷（每岗位 3 题）、全天候自动收集、加权自动核算与点评生成、结果统一公示。管理端「工作台」可视化当前流程进度，并保留人工触发入口（全程留痕）。
- **极致匿名 + 操作留痕**：打分明细（Submission）不含任何评价人身份字段，参与状态单独存储、相互隔离；超级管理员全部后台操作（登录、核算、公示、查看等）永久写入操作日志，可追溯、可审计。
- **权重动态升降**：基础权重 1.00，每月按时参与 +0.05（上限 1.50），当月未参与 −0.10（下限 0.30）。得分按「评分 × 权重」加权核算，长期不参与者的打分影响力持续弱化。
- **历史数据导入**：管理端「数据导入」支持 Excel 批量导入历史月份的正式统计数据，导入后直接以「已公示」状态纳入系统。
- **一键清空**：工作台「清空全部数据」可将系统回归空白正式状态，仅保留管理员账号。

## 角色与账号

| 角色 | 账号 | 密码 |
| --- | --- | --- |
| 超级管理员（鲍学亮） | `admin` | `admin123` |
| 评价员工 | 管理员在「人员管理」创建，或由数据导入自动建档（工号即账号） | 初始密码 `123456` |

## 页面

- 员工端：`/evaluate` 匿名打分、`/results` 结果公示
- 管理端：`/admin` 工作台、`/admin/results` 评价结果（图表 + 明细 + 点评）、`/admin/participation` 参与情况（含未参与名单）、`/admin/users` 人员管理（新增 / 删除 / 角色调整 / 重置密码）、`/admin/staff` 岗位人员（新增 / 删除 / 调整岗位 / 关联参评账号自动回避）、`/admin/import` 数据导入、`/admin/weights` 权重管理、`/admin/logs` 操作日志

## 数据导入说明

1. 在「数据导入」页**下载模板**，按「月度得分」「参与情况」「周期点评」三张表填写（后两张可留空）。
2. 「月度得分」按「每个被评对象 × 每个月」一行填写平均得分与评价份数；姓名不存在时自动新建岗位人员。
3. 「参与情况」中的工号不存在时，填写姓名即可自动创建员工账号（初始密码 123456）。
4. 系统中已存在的月份会自动跳过，不会重复导入；历史数据不追溯权重调整。
5. 上传后先校验（逐行报出表名 + 行号），确认无误再正式导入。

## 技术栈

React 19 + TypeScript + Vite + Tailwind CSS + shadcn/ui + Recharts + xlsx；HashRouter，数据存于浏览器 `localStorage`。

## 本地运行

```bash
npm install
npm run dev      # 开发预览
npm run build    # 产出 dist/
```

## 说明

当前为前端一体化实现，数据保存在浏览器本地（清缓存会丢失）。正式上线需接入后端（账号体系、数据库、定时任务与邮件推送），前端结构已按此预留（store 层集中数据操作，可平滑替换为 API）。
