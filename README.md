# 满意度自动测评平台

内部支撑岗位（平台运营支撑 / 网络终端技术支撑 / 投诉管理（班长））月度满意度自动测评系统，替代原「问卷星 + 人工统计」模式。

## 功能

- **全流程自动化**：评价周期自动启动（通知）、按三类工种自动生成问卷（每岗位 3 题）、全天候自动收集、加权自动核算与点评生成、结果统一公示。管理端「工作台」可视化当前流程进度，并保留人工触发入口（全程留痕）。
- **极致匿名 + 操作留痕**：打分明细（Submission）不含任何评价人身份字段，参与状态单独存储、相互隔离；超级管理员全部后台操作（登录、核算、公示、查看等）永久写入操作日志，可追溯、可审计。
- **权重动态升降**：基础权重 1.00，每月按时参与 +0.05（上限 1.50），当月未参与 −0.10（下限 0.30）。得分按「评分 × 权重」加权核算，长期不参与者的打分影响力持续弱化。

## 页面

- 员工端：`/evaluate` 匿名打分、`/results` 结果公示
- 管理端：`/admin` 工作台、`/admin/results` 评价结果（图表 + 明细 + 点评）、`/admin/participation` 参与情况（含未参与名单）、`/admin/weights` 权重管理、`/admin/logs` 操作日志

## 技术栈

React 19 + TypeScript + Vite + Tailwind CSS + shadcn/ui + Recharts；HashRouter，数据存于浏览器 `localStorage`（含演示种子数据：2026-09 / 2026-10 已公示周期与 2026-11 进行中周期）。

## 本地运行

```bash
npm install
npm run dev      # 开发预览
npm run build    # 产出 dist/
```

## 说明

当前为前端一体化实现，数据保存在浏览器本地（清缓存会丢失），用于流程演示与原型验证。正式上线需接入后端（账号体系、数据库、定时任务与邮件推送），前端结构已按此预留（store 层集中数据操作，可平滑替换为 API）。
